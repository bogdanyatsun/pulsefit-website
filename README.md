# PULSE FIT — Modern Responsive Fitness Website

A modern, high-performance 3-page website built for fitness clubs, CrossFit boxes, and personal trainers.

## Features
- **3 Responsive Pages:** Home (`index.html`), Programs & Pricing (`programs.html`), and Community Gallery (`gallery.html`).
- **Lead Capture:** Opt-in newsletter form with promo-code confirmation feedback.
- **Booking Modal:** Interactive appointment popup integrated with tier selector and keyboard accessibility (`ESC` close).
- **Interactive Lightbox:** Full-screen modal viewer for gallery showcases.
- **Speed Optimized:** Built with modern Tailwind CSS v4 and optimized next-gen image assets.

## Quick Start
1. Clone or extract the project folder.
2. Open `index.html` directly in any modern browser.

## Development & Tailwind Compilation
If you wish to edit Tailwind styles:
1. Run `npm install` to install dependencies.
2. Run `npm run dev` to start real-time CSS watcher.
3. Run `npm run build` to compile the minified production stylesheet.
